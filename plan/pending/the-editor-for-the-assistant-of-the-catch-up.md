# The editor for the assistant of the catch-up

**Status:** a plan with steps since 2026-11-19 (section 4). Each step starts only after the owner
approves it. The lists were written 2026-11-18 by the assistant of the
campaign window of omnet-julia, which follows the INET baseline catch-up in the IDE
(`bin/omnet_ide --assistant=acp ~/workspace/ghci-baseline-catch-up`), at the request of the
owner: "collect the issues which should be fixed in the next version of the editor to make your
life easier". The findings come from the live check of
[the-ide-follows-the-baseline-catch-up.md](../../../omnet-julia/plan/pending/the-ide-follows-the-baseline-catch-up.md)
(omnet-julia, step 11), which holds the details of each case. The assistant adds a row when it
meets a new one.

different, and each cost a failed call and a search:

| N1 | `Explorer` | Not among the names; `ExplorerSection` and `Dashboard` are. The assistant took it from `ProjecturedPlatform.ExplorerModule`. | List `Explorer` with the explorer verbs. Done 2026-11-20, commit `0c3c7ac9d` on main: the docstring of `Explorer` carries the mark, and its example opens an explorer of a new section with `open_pane!`. |
| N2 | `Dates`, `ProjecturedKernel`, `ProjecturedPlatform` | Not imported in the scratch module; a `Dates.unix2datetime` or a type name with its module fails. | Import `Dates` in the scratch module; say in the system text how to reach a module. | N3 | `get_file_disk_state`, `is_folder_watched`, `find_file_change_store` | Not in the names; `is_folder_watched(store, folder)` differs from its real signature `is_folder_watched(path; store, receiver)`. | The state of a file against the disk as a verb for the assistant: the counts of the watch, the band, the stamp. ## 4. Order of the work

The owner and the assistant of the session "catch-up assistant" set this order on 2026-11-19.

the owner approves it. A fix reaches the IDE of the owner only after a new build of `omnet_ide`
and a restart, which stops the walk for a moment; so one build follows steps 1 and 2.
