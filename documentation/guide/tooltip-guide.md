# The tooltip

> **Kind:** procedure · **Status:** current · **Stands on:** [pointer-guide.md](pointer-guide.md)

The small window that says what a part is, how to see more of what is around
it, and the ways to close it.

## Open it

1. Stop the pointer over a part: a button, a field, a row, anything that has
   something to say about itself.
2. Wait about half a second. A small window opens near the part and says what
   it is.

Not every part has something to say. Where it does not, no window opens.

## See what is around it too

While the window is open:

- Press F2 to add what the part around it says. The window grows by one line, a
  separator, and the name of that part.
- Press Shift+F2 to go back to one fewer.

## Close it

Any of these closes the window:

- Move the pointer off the part.
- Press Escape.
- Click, scroll, or move the pointer out of the window the part is in.

Any other key still goes to what you were doing, so a key that you type does
not close the window.

## Show the tooltip with no pointer

1. Select the part.
2. Open the command palette (Ctrl+Shift+P) and type "Show the tooltip".
3. Press Enter. The window opens below the part.

See [the pointer](pointer-guide.md) for the light that marks the part the
pointer is on, and [the keyboard and the mouse](keyboard-and-mouse-guide.md)
for the full list of keys.
